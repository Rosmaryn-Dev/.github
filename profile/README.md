# Rosmaryn

Rosmaryn is a holistic self-knowledge platform that brings together Human Design, astrology and numerology. It offers free calculators, an encyclopedia, software for practitioners, online courses and a library of esoteric books, in six languages: French, English, German, Spanish, Italian and Brazilian Portuguese.

Charts are computed by Rosmaryn's own engine, from NASA JPL DE430 ephemerides, directly in the visitor's browser.

## Browser extension

[Rosmaryn Holistic Addon](https://addons.mozilla.org/firefox/addon/rosmaryn-holistic-addon/) for Firefox and Firefox for Android: select a birth date on any page to see the sun sign, then open the birth chart or the Human Design Body Graph on Rosmaryn. Source: [rosmaryn-holistic-addon](https://github.com/Rosmaryn-Dev/rosmaryn-holistic-addon).
